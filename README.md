# 鼠标跟手度测试工具 使用说明与原理介绍

本工具用于量化评估 **VDI / 桌面云环境下鼠标的「跟手度」**，即系统光标相对于实际鼠标位置的落后程度。

工程由两个相互独立的程序组成：

| 程序 | 用途 | 入口类 |
|------|------|--------|
| `MouseDragTest.py` | 自动化跟手度测试（画圆拖动 + 距离统计 + 趋势图 + 历史记录） | `DistToolWindow` |
| `MousePanel.py` | 测试场景面板（全屏背景 + 轨迹点 + 时间显示 + 提示方框） | `MainWindow` |

两者通常配合使用：`MousePanel.py` 全屏铺一层稳定的测试背景与定位方框，`MouseDragTest.py` 在其中自动画圆并测量鼠标距离偏差。

## 二、MouseDragTest.py — 自动化跟手度测试

### 2.1 功能概览

`MouseDragTest.py` 是该工具的核心。它做三件事：

1. **在指定屏幕区域自动模拟鼠标画圆**（`QCursor.setPos` 按圆周点位移动）。
2. **实时截图检测屏幕上的黑点（被拖动的图元）质心**，计算「鼠标光标」与「黑点质心」之间的像素距离。
3. **对距离序列做统计**（均值 / 平滑度=标准差），记录 CSV、绘制趋势图、维护历史记录表。

**跟手度的物理含义**：远处有一被拖动的黑色点（代表画面中实际被拖拽的图元），当鼠标快速移动时，画面渲染会滞后于鼠标指令。滞后越明显，「鼠标光标」与「黑点」的像素距离就越大。该距离即跟手度指标，越小越跟手。

### 2.3 使用流程

**Step 1 — 选择测试区域**

点击「选择测试区域」，屏幕会覆盖一层 15% 透明度的橡皮筋选择层（`RubberBand`），鼠标移动时以光标为中心画出固定 **500×500** 正方形选框，点击释放后用红框确认。松开鼠标即把 `left/top/width/height` 写入 X/Y/W/H 坐标框。

也可以勾选「显示检测区域配置」手动输入 X/Y/W/H。检测区域必须**完整覆盖被拖动的黑点**，且黑点应保持在该区域内（画圆半径 = 区域内切正方形的一半再留 2px 边距）。

> 「预览」按钮当前被代码隐藏（`self.preview_btn.setVisible(False)`），功能暂未放开。

**Step 2 — 配置检测参数（可默认）**

| 参数 | 默认 | 说明 |
|------|------|------|
| 黑点阈值 | 60 | RGB 均值 < 阈值即判为黑点。背景越亮、黑点越纯，可保持默认；若误检背景可将阈值调小 |
| 最小面积 | 5 | 小于该像素面积的轮廓被忽略，用于滤除噪点 |

**Step 3 — 开始测试**

点击「开始测试」，程序在检测区域内切正方形中自动画圆：

1. 路径为圆周上均匀分布的 `点数`（默认 1200）个点。
2. 定时器每隔 `interval = 10000 / (speed * 100)` 毫秒移动鼠标到下一个点（`速度` 默认 30 → 约 3.3ms/点）。
3. **第一圈不记录**（作为缓存预热），从第二圈开始统计，倒数第二圈结束记录。
4. 画满 `次数` 或达到 `时间` 后自动停止，并弹出统计结果。

按 **Esc** 或点击「按Esc键停止测试」可随时中断。

**Step 4 — 查看结果**

- **距离均值**：所有采样点距离的算术平均，单位像素。这是最核心的跟手度指标。
- **平滑度**：距离的标准差，反映抖动程度。标准差越小说明跟手越稳定。
- **鼠标延迟(毫秒)**：由距离均值得出，经验换算公式 `延迟 = 均值 × 2.34`（毫秒）。
- **趋势图**：本次测试距离随采样次数的变化曲线，横轴为采样序号，纵轴为像素距离，可用于观察起止阶段的爬升/收敛形态。
- **历史记录表**：每完成一次测试追加一行，包含序号、时间、延迟、均值、平滑度、备注、详细数据 CSV 路径。双击「备注」列可编辑并自动写回汇总 CSV；单击某一行会用该行对应的详细 CSV 重绘趋势图。

### 2.4 关键配置项

**自动测试配置**（勾选「显示自动测试配置」后展开）：

| 项 | 默认 | 说明 |
|----|------|------|
| 速度 | 30 | 数值越小越慢，`1~100` 映射到约 100ms ~ 1ms/点 |
| 点数 | 1200 | 圆周采样点数，越多圆越平滑（8 ~ 3000） |
| 按次数 / 按时间 | 按次数 | 两种停止条件二选一 |
| 次数 | 10 | 画圈次数（按次数模式） |
| 时间(秒) | 10 | 画圈时长（按时间模式） |
| 统计均值 | 勾选 | 启用后累计距离并计算均值/标准差 |
| CSV记录 | 勾选 | 把每次采样的坐标与距离写入明细 CSV |
| 统计间隔 | 50 ms | 独立统计线程的采样间隔（`多线程统计` 默认开启） |
| 自动校准模型 | 勾选 | 见下节 |

**间隔置顶窗口**：勾选后每 5 秒自动 `raise_()` 当前窗口，防止被全屏面板遮挡。

### 2.5 自动校准模型

用「点数」间接控制画圈速度并不直观，因为不同机器 / 环境下每个点位移动的耗时不同。自动校准在正式测试前先自我调参：

- **目标**：单圈耗时接近 **3600ms**。
- **流程**：校准阶段先画 2 圈测出单圈耗时 `lap_ms`。
  - 若 `3500 ≤ lap_ms ≤ 3700` → 校准通过，进入正式测试。
  - 若偏快（`< 3500`）→ 增加点数；若偏慢（`> 3700`）→ 减少点数。
  - 点数按线性比例调整：`新点数 ≈ 1200 ± (偏差 / 单点平均耗时)`。
  - 每次调整后再画 2 圈复测，最多尝试 **15 次**，超限则直接进入正式测试。
- **效果**：使不同环境下的画圈速度归一化，从而让不同机器测得的距离值具有可比性。

  | 备注 | 用户可编辑 |

### 2.7 底层原理

**黑点检测（`capture_screen_region` + `detect_one_dot`）**

1. 用 `mss` 抓取检测区域的 BGR 位图，转成 `numpy` 数组（RGB）。
2. `gray = np.mean(region, axis=2)` 求灰度，`gray < threshold` 二值化成黑白掩码。
3. `cv2.findContours` 取最大轮廓，用 `cv2.moments` 求质心 `(m10/m00, m01/m00)`。
4. 质心 + 区域左上角偏移 = 黑点的屏幕绝对坐标。

**距离计算**

```python
dist = sqrt((mouse_x - dot_x)^2 + (mouse_y - dot_y)^2)
```

**时间对齐（关键）**

距离的准确性依赖「截图时刻」与「鼠标坐标读取时刻」的紧密对齐。代码在**黑点检测完成后立即**调用 `QtGui.QCursor.pos()` 读取鼠标坐标（见 `StatsThread.run` 与 `_do_measure`），以最大程度减小两个采样动作之间的时间差，避免引入额外的测量误差。

**统计线程（`StatsThread`）**

画圆本身由主线程的 `QTimer` 驱动，若在同一线程里做截图+opencv 检测会拖慢画圈频率。因此统计被放入独立 `QThread`：

- 主线程只负责按定时器移动鼠标（保证画圈速度稳定）。
- 统计线程按 `stats_interval_ms` 独立执行「截图 → 检测 → 读鼠标 → 算距离」，并通过 `distance_recorded` 信号把结果发回主线程更新 UI / 写 CSV。
- `QMutex` + `running` 标志控制线程的启停。

这样设计后，无论检测多慢，鼠标画圆的节奏都不受影响——这是保证跟手度测量可重复性的前提。

## 三、MousePanel.py — 测试场景面板

### 3.1 功能概览

`MousePanel.py` 是一个**全屏测试背景板**（v2 版本）。它本身不测量任何数据，作用是为跟手度测试提供稳定的视觉基准环境：

- 铺一层整屏颜色 / 动态渐变背景。
- 在光标位置绘制一个**轨迹圆**（红/可调色，代表系统实际绘制位置）。
- 在屏幕中央绘制一个**600×600 淡蓝色方框**，提示「把测试的区域放置于如下的方框内」。
- 可选在屏幕中部显示**系统启动时长**与**当前日期时间**两行大字（用于长时间稳定性测试时观察是否卡顿 / 时间是否跳变）。

### 3.2 工具栏说明

| 控件 | 功能 |
|------|------|
| 坐标圆半径 / 颜色 | 调节跟随光标的轨迹圆大小与颜色 |
| 光标圆半径 / 颜色 | 调节**系统光标本身**绘制成的圆点大小与颜色（`make_dot_cursor` 生成自定义光标） |
| 背景颜色 | 选择纯色背景 |
| 渐变色 | 开关动态渐变背景 |
| 设置渐变 | 打开渐变色编辑对话框 |
| 速度(ms) | 渐变旋转定时器间隔，越小越快 |
| 步长(°) | 每帧旋转角度，越大越快 |
| 显示时间 | 开关时间显示 |
| 时间颜色块 | 选择时间字体颜色 |
| 字号 | 时间字体缩放系数（0.5 ~ 2.5 倍） |
| 全屏 | 切换全屏 / 普通窗口 |

按 **Esc** 关闭窗口。

### 3.3 动态渐变背景原理

- 使用 `QtGui.QConicalGradient(center, angle)` 创建锥形渐变，按 `gradient_colors`（颜色+位置停靠点列表）设置颜色。
- 一个 `QTimer` 以 `gradient_interval` 毫秒为周期，每帧把 `gradient_angle` 增加 `gradient_step` 度并 `update()` 重绘，形成旋转的彩虹背景。
- 在 `paintEvent` 中绘制，同时关闭 `setAutoFillBackground` 避免纯色覆盖渐变。

### 3.4 时间显示原理

- 用 Windows API `GetTickCount64`（`ctypes.windll.kernel32`，声明返回 64 位无符号）获取系统已运行毫秒数，换算成「X天X小时」。相比 `time.clock`，可正确跨过 24.8 天（32 位溢出）边界。
- 当前时间用 `time.strftime` 格式化。
- 一个 500ms 周期的 `QTimer` 触发重绘，保证秒数在走动。
- 字号自适应：`fit_font` 从 16pt 起递增，直到文字宽度达到窗口宽度的 97%，使两行大字横向撑满、贴近左右两边。字号结果按 `(文本, 缩放, 窗口宽度)` 缓存，避免每 500ms 重做耗时的字形测量循环。

### 3.5 与 MouseDragTest 的配合

1. 先运行 `MousePanel.py` 并点「全屏」，让测试背景铺满整个屏幕。
2. 把 VDI 客户端窗口（或被测画面）按面板中央的 600×600 蓝框摆放，使被拖拽的黑点稳定落在框内。
3. 运行 `MouseDragTest.py`，框选包含该黑点的检测区域，开始自动画圆测试。

## 四、跟手度指标与换算

| 指标 | 计算 | 含义 |
|------|------|------|
| 距离均值 | 采样距离的算术平均（像素） | 核心跟手度，越小越跟手 |
| 平滑度 | 采样距离的标准差（像素） | 越小越稳定，越大越抖 |
| 鼠标延迟 | 距离均值 × 2.34（毫秒） | 经验换算的时延估计 |

> 换算系数 2.34 为经验值，用于把「像素滞后」粗估成「时间滞后」。若要精确换算，应结合实测的画圆线速度（像素/秒）反推。

**测试建议**

- 每次测试前先用「自动校准模型」把单圈耗时归一到 3600ms，保证不同机器 / 不同版本的结果可横向对比。
- 检测区域要足够覆盖黑点的整个运动轨迹，避免黑点移出区域导致漏检。
- 背景越干净、对比度越高，检测越稳定；可配合 `MousePanel.py` 的纯色/渐变背景消除干扰。
- 长时间稳定性测试时开启 `MousePanel.py` 的时间显示，便于观察掉帧与时延跳变。

## 六、常见问题

**Q：距离始终显示 `--` / 未检测到黑点？**
A：检测区域没覆盖黑点，或黑点阈值 / 最小面积不合适。检查 X/Y/W/H 是否框住黑点，适当调大「黑点阈值」，确认画面里确有足够黑的目标。

**Q：画圈速度忽快忽慢？**
A：关闭「多线程统计」以外的干扰，确认「自动校准模型」已勾选；环境 CPU 占用过高也会影响定时器精度。

**Q：不同机器测出的均值差异很大，无法对比？**
A：先确认都开启了自动校准（单圈耗时归一到 3600ms），并保证检测区域、点数、阈值等参数一致。

**Q：运行时卡顿 / 鼠标跳变？**
A：这是被测环境的真实表现，正是本工具要捕捉的现象；也可据此判断 VDI 画面渲染是否跟得上鼠标输入。
